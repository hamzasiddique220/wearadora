# WEARADORA — Logo Kit & Brand Guide

## Logo files (kahan use karna hai)

| File | Use kahan |
|---|---|
| `wearadora-profile-dark.png` | **WhatsApp, Instagram, TikTok profile photo** (dark — recommended). Square, circle-crop safe. |
| `wearadora-profile-cream.png` | Profile photo ka light/cream version (jahan light look chahiye) |
| `wearadora-wordmark-light.png` | **Website header** (dark background pe) — transparent PNG |
| `wearadora-wordmark-dark.png` | Website header (light background pe) — transparent PNG |
| `wearadora-monogram-gold.png` | Chhoti jagah — favicon, watermark, stamp, packaging — transparent |
| `wearadora-icon-dark.png` | App icon / square mark (espresso bg + gold W) |

> Profile photos circle mein crop hote hain — sab content already safe circle ke andar hai, kuch katega nahi.

## Colors (brand palette)
- **Espresso** `#1A1614` — background, primary dark
- **Antique Gold** `#C8A66C` — accents, sparkle, premium feel
- **Soft Gold** `#D6B884` — wordmark on dark
- **Cream / Ivory** `#F4EEE2` — light background, text on dark

## Fonts
- **Wordmark:** Italiana (elegant high-fashion serif)
- **Tagline:** Arsenal SC (small caps)
- Website pe yeh fonts free hain (Google Fonts) — `Italiana` aur `Arsenal` import kar sakte ho.

## Usage tips
- Logo ke around hamesha thodi khaali jagah (breathing space) rakho — bheed mat karo.
- Stretch / squeeze mat karo — proportion barقرار rakho.
- Dark background pe gold/cream version, light background pe dark version.
- Tagline "Adorned in Artistry" optional hai — bahut chhoti jagah pe sirf monogram/wordmark kaafi hai.
